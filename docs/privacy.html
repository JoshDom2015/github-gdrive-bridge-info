Privacy Policy

Effective 18 November 2026. This policy applies to the private GitHub–Google Drive Bridge operated by Dominic.

Data accessed and purpose

The integration requests Google Drive read and write access for the authorized working account. It uses that access only to let authorized, manually triggered GitHub Actions read, download, create, and update files in the designated working folder. Google grants the OAuth scope across the account's Drive; rclone's root folder setting directs routine operations to the working folder.

Storage and sharing

OAuth credentials and tokens are stored as encrypted GitHub Actions repository secrets. A workflow uses them in a temporary runner configuration and removes that configuration at the end of the run. Selected files pass between Google Drive and GitHub Actions. Requested downloads may be retained as private GitHub Actions artifacts for one day. No Google Drive file content is placed on this public website, sold, or used for advertising.

Retention and control

Files created or updated in Drive remain under the working account's normal Drive controls. The integration does not automatically delete or synchronize files. The operator can revoke access in the Google account's connected-app settings and can remove GitHub Actions secrets. GitHub and Google process data according to their applicable service terms and privacy policies.
