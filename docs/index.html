GitHub–Google Drive Bridge

This is a private, single-user integration operated by Dominic. It lets manually triggered GitHub Actions use rclone and the Google Drive API to transfer files to and from an authorized Google Drive working folder.

How it works

The authorized Google account grants OAuth access to Google Drive. The workflow configures rclone to start in the designated working folder. The OAuth permission itself applies to the account's Drive, so the folder setting is an operational safeguard, not a restriction imposed by Google.

Workflows can create, read, download, and update files when manually started by an authorized repository user. There is no scheduled synchronization or automatic deletion. Files are not published by this website.
